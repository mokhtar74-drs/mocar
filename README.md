# Mocar

Bilingual (Arabic and English) car dealership website. It is a static site with no build step.

Live site: https://mokhtar74-drs.github.io/mocar/

To run it locally, open `index.html` or serve the folder:

```
python -m http.server 8080
```

- `assets/js/`: site data, interface text and page logic
- `assets/css/style.css`: design; the brand colours are at the top of the file
- `assets/img/`, `assets/fonts/`: images and fonts
- `brand/`: logo files
